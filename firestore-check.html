Доступ к Firestore

Отдельная проверка из GitHub Pages. Она использует только временные тестовые документы и не обращается к базе Timeweb.

01Доступ к адресу API

Проверим, получает ли браузер JSON от Google. Для этого проект Firebase ещё не нужен.

02Запись и чтение

Нужен отдельный пустой проект с базой Cloud Firestore (default) и временными правилами ниже. Вводи ID проекта, а не его название.

Пароль, API-ключ и доступ к Google-аккаунту эта страница не запрашивает.

    Временные правила для тестового проекта

    Firestore Database → Rules. Правила разрешают только документы проверки с фиксированным содержимым. Действуют 24 часа после генерации. Используй их в отдельном тестовом проекте.

    Проверка выполняет PATCH → GET → DELETE и подтверждает удаление документа. Успех показывает доступность этих REST-запросов; Firebase Auth, WebSocket и SDK-синхронизация здесь не проверяются.

    Рабочее приложение и его данные не изменяются.
