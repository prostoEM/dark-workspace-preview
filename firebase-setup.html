Подключить пространство

GitHub-версия подключается к проекту do-it-5caf6 напрямую. Данные Timeweb сюда не перенесены.

Это временное пространство без входа. Его данные доступны по публичному адресу. Используйте вымышленные задачи для проверки.

Правила на 24 часа

Скопируйте правила ниже в Firebase → Firestore → Rules и нажмите Publish. Затем откройте приложение.

Доступ разрешён только к одному тестовому документу workspaces/preview и документам проверки связи. Остальные пути закрыты. Документы по истечении срока не удаляются.

Открыть Do it →

Тестовая версия хранит пространство одним документом (до 850 КБ). Таймер восстанавливается по сохранённым интервалам; точность зависит от часов устройства. Без сети запись не подтверждается. Это ещё не замена серверного backend.
