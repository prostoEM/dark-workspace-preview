Личное пространство с Google

В Firebase Authentication включите Google. Публичное имя приложения — Do it. В Authorized domains добавьте prostoem.github.io.

Эти правила разрешают каждому вошедшему пользователю только его документ users/{uid}/workspaces/main. Прежний общий документ workspaces/preview закрыт. У правил нет срока действия.

Перед переключением сохраните резервную копию общих записей. При первом Google-входе они не импортируются автоматически. Владелец будет назначен отдельно по подтверждённому UID.

Не публикуйте прежние правила с allow read/write: if true. Firebase Console с административными правами сохраняет возможность переноса архива.
